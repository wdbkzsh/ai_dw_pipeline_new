# 农户生产异常预警分析 - 业务需求分析报告

## 1. 项目业务理解

### 1.1 项目背景

本项目为温氏集团**育肥作业管理**业务域下的**农户生产异常预警分析看板**建设。系统基于苍穹平台，通过采集农户生产过程中的死淘率、采食量等核心指标，自动触发预警，并关联巡查工单进行闭环管理。

当前处于 **0→1 数仓建设阶段**，需要将业务需求转化为可落地的指标体系和数据模型。

### 1.2 业务目标

1. **实时监控**：掌握各分公司农户生产异常的现状（异常农户数、占比、预警分布）
2. **归因分析**：分析异常原因分布及策略有效性
3. **效果评估**：评估预警关闭率、7天复发率、有效干涉率等核心运营指标
4. **趋势追踪**：按月追踪核心指标变化趋势

### 1.3 服务对象

- 分公司管理人员
- 运营管理人员
- 业务决策层

## 2. 页面需求分析

### 2.1 页面概述

原型为**农户生产异常运营看板（分公司）**，是一个面向分公司的运营监控大屏，包含以下核心区域：

| 页面区域 | 业务用途 |
|---------|---------|

| 持续中预警区 | 展示当前持续中预警的细分状态 |
| 预警类型趋势 | 按预警指标分类的异常养户分布（折线图） |
| 预警等级趋势 | 按预警等级分类的异常养户分布（柱状图） |
| 预警清单 | 异常预警记录明细表格 |

## 3. 业务对象识别

### 3.1 养户（Rearer）

- **业务含义**：与温氏签订合作协议的养殖户，是生产管理的基本单元
- **业务粒度**：一个养户档案 = 一个独立的养殖合作主体
- **核心属性**：养户编码、养户名称、组织、养殖场、管理员、饲养状态、开户人

### 3.2 猪群（Flock）

- **业务含义**：一个养户下的一批养殖猪群，是生产跟踪的基本单位
- **业务粒度**：一个畜禽档案 = 一个养户下的一批猪群
- **核心属性**：编码、名称、养户档案、饲养品种、猪群状态、进苗日期、存栏量、饲养批次

### 3.3 预警事件（Alert Event）

- **业务含义**：当农户生产过程中死淘率或采食量等指标触发阈值时，系统自动产生的预警记录
- **业务粒度**：一条预警单据 = 一次生产异常预警事件
- **核心属性**：单据编号、组织、养户、猪群编码、预警指标、预警等级、触发预警时数值、预警时间、预警状态、持续时长、是否巡查

### 3.4 巡查工单（Patrol Ticket）

- **业务含义**：针对持续中预警，由运营人员发起的现场巡查处理单据
- **业务粒度**：一条巡查工单 = 一次巡查处理事件
- **核心属性**：单据编号、组织、养户、猪群编码、预警指标、预警等级、预警状态、巡查工单状态、预警单据编号、执行人

### 3.5 应对策略（Handle Strategy）

- **业务含义**：针对异常原因预定义的风险分类和应对策略参考库
- **业务粒度**：一条策略记录 = 一条风险-策略映射关系
- **核心属性**：名称、组织、组织层级、风险大类、风险项、对应策略

## 4. 业务过程分析

### 4.1 预警事件产生

- **类型**：event
- **粒度**：一条预警事件（wens_production_anomaly 一行）
- **描述**：系统根据生产数据（死淘率、采食量）与预设阈值对比，自动生成预警记录。每条记录关联一个养户的一个猪群，标记预警指标、等级、触发值和时间。

### 4.2 巡查处理

- **类型**：event
- **粒度**：一条巡查工单（wens_patrol_ticket 一行）
- **描述**：针对持续中预警，运营人员创建巡查工单，记录风险分析、应对策略和执行结果。工单通过预警单据编号关联原始预警事件。每个工单包含两个分录：
  - 原因分析分录（tk_cause_analysis）：关联应对策略，记录风险大类、风险项、对应措施及是否执行/采纳
  - 自定义风险分录（tk_wens_risk_item_entry）：记录自定义风险大类、风险项、策略及是否执行/采纳

### 7.5 7天复发率规则

- **条件**：组织 + 养户 + 猪群编码 + 预警指标 + 预警等级 一致
- **时间判断**：两条预警的触发时间间隔 ≤ 7天
- **复发定义**：满足上述条件的同一组内出现两条及以上预警，即为复发

### 7.6 预警关闭占比规则

- **分子**：预警状态为"已关闭"的记录数
- **分母**：全部预警记录数

### 7.7 策略有效性规则

- **分子**：是否忽略为"否"（即采纳）的分录条数
- **分母**：全部分录条数
- **数据来源**：巡查工单的两个分录（原因分析分录 + 自定义风险分录）

### 7.8 数据关联规则

- 预警 → 巡查工单：通过 `wens_warning_billno`（预警单据编号）关联
- 预警 → 养户：通过 `fk_wens_basedatafield` 关联 `wens_rearer_farm_pig`
- 预警 → 猪群：通过 `fk_wens_recbrlrflk_pig` 关联 `wens_recbrlrflk_pig`
- 巡查工单 → 应对策略：通过 `tk_cause_analysis` 分录的 `fk_wens_handle_strategy` 关联 `wens_handle_strategy`
